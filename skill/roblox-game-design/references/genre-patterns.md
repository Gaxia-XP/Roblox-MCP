# Genre Patterns — Roblox

## Simulator
**Pattern:** Idle loop ที่ผู้เล่น AFK ได้แต่ยังได้ของ
- Income แบบ passive (auto-collect เมื่อ offline)
- Rebirth system เพื่อ reset แล้วแรงขึ้น
- Pet/Companion ระบบที่ช่วย boost
- ตัวอย่าง: Pet Simulator, Bee Swarm Simulator

**สิ่งสำคัญ:**
- Prestige/Rebirth cycle ให้ผู้เล่นรู้สึกก้าวหน้า
- Number ต้องใหญ่ขึ้นเรื่อยๆ (satisfying)
- Leaderboard แสดงตัวเลข เปรียบเทียบกับคนอื่นได้

---

## RPG / Dungeon
**Pattern:** Combat → Loot → Power up → Hard combat
- Class/Job system
- Equipment rarity (Common → Legendary)
- Party system สำหรับ raid boss
- ตัวอย่าง: Deepwoken, Arcane Odyssey

**สิ่งสำคัญ:**
- Combat ต้องรู้สึก "มีน้ำหนัก" (hit feedback, sounds)
- Loot drop rate ต้องสมดุล — หายากแต่ไม่หมดหวัง
- Story/Lore เพิ่มความลึก

---

## Obby (Obstacle Course)
**Pattern:** Stage → Checkpoint → Next Stage
- Linear progression ชัดเจน
- Checkpoints ถี่ช่วงต้น ห่างขึ้นช่วงท้าย
- ตัวอย่าง: Tower of Hell, Mega Fun Obby

**สิ่งสำคัญ:**
- Instant respawn — อย่าให้รอนาน
- ความยากต้องขึ้นแบบ smooth
- Badge/cosmetic reward ทุก milestone

---

## Tycoon
**Pattern:** ซื้อ → สร้าง → Income → ซื้อต่อ
- Conveyor belt income แบบ classic
- หรือ Modern: ซื้อ buildings แล้วรับ passive income
- ตัวอย่าง: Theme Park Tycoon, Restaurant Tycoon

**สิ่งสำคัญ:**
- ให้ผู้เล่นเห็น "empire" ของตัวเองใหญ่ขึ้น
- Multiple income streams เพื่อลด grinding
- Cosmetic customization ให้รู้สึกเป็นเจ้าของ

---

## Horror / Escape Room
**Pattern:** Explore → Solve puzzle → Survive → Escape
- Atmosphere ต้องสร้าง tension ด้วย sound + lighting
- Jump scares ต้องไม่บ่อยเกินไป (จะเคยชิน)
- ตัวอย่าง: Flee the Facility, The Mimic

**สิ่งสำคัญ:**
- Sound design สำคัญมาก
- Collaborative mechanics (ต้องช่วยกัน)
- Procedural elements ให้เล่นซ้ำได้

---

## Competitive / PvP
**Pattern:** Queue → Match → Result → Rank up/down
- Matchmaking ต้องจับคู่ระดับใกล้เคียงกัน
- Match length 5-10 นาที เหมาะที่สุด
- ตัวอย่าง: Arsenal, Blox Fruits PvP

**สิ่งสำคัญ:**
- Ranked system ให้มีเป้าหมาย
- Season reset ทุก 1-3 เดือน
- Balance อาวุธ/class สำคัญมาก
